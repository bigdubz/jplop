# windows
1- run `fetch.ps1` (it's going to download ~2 GB worth of model, llama, and dictionaries)

2- run jplop.exe (might take a min on first run to build the dictionary database)

# arch linux
1- have cargo

2- run 'run_fetch.sh' (it's going to download ~2 GB worth of model, llama, and dictionaries)

3- 'cargo run --bin jplop'
